# Experiment Overview

## synthetic_articulated_gaussians

Tests whether a method can solve the central two-state articulated object problem on a compact procedural benchmark. The experiment measures whether the recovered motion, part decomposition, and reconstructed state geometry are jointly correct, and compares against a static-object baseline that cannot explain moving parts.

## paper_paris_pms_articulation_reconstruction

Paper-reported aggregate target for the established PARIS-PMS benchmark. This records the expected full-scale articulation and mesh reconstruction behavior for future agents that extend the environment to the original image-rendering pipeline.

## paper_splart_pms_articulation

Paper-reported aggregate target for the authors' harder SPLART-PMS benchmark, including ablations. This records the robustness target for future work; it is not generated by the current lightweight evaluator.
